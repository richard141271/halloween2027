# NATTORDREN 2027

Statisk GitHub Pages-utkast for nattordren.no.

- `index.html`: forside
- `historien.html`: legenden
- `mysteriet.html`: årets oppdrag
- `arkiv.html`: årsarkiv
- `nfc/post-1/`, `nfc/post-2/`, `nfc/post-3/`: NFC-landingssider
- `kort/`: demonstrasjon av deltakerkort
- `assets/`: felles CSS og JavaScript

Dette er en statisk førsteversjon. Ingen deltakerdata lagres. Database og personlige profiler må bygges senere.
